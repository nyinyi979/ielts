# IELTS Master Guide — Vite + React

A four-page, mobile-responsive IELTS study app built around examiner criteria and practical training systems. The Writing guide covers both Academic and General Training.

## Pages
- Writing — 23 copyable frameworks covering Academic Task 1 visuals, General Training letters and all common Task 2 essay families, plus idea banks, a word-choice explorer, examiner checklist and training plan
- Reading — evidence system, question-type playbook, error clinic, score guide and practice links
- Listening — prediction loop, distractors, maps, score guide, transcript-review system and practice links
- Speaking — examiner criteria, Parts 1–3 strategies, pronunciation, language bank and recording drills

## Features
- Light / dark mode with saved preference
- Responsive desktop + mobile navigation
- Expandable language banks
- Practice timers
- Persistent mastery checklists using localStorage
- Approximate Reading / Listening raw-score band guide
- Official practice links plus clearly labelled supplementary tools

## Run

npm install
npm run dev
