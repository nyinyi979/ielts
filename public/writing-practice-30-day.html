How to use this pack

Daily timing

  • Task 1: 20 minutes · 150+ words
  • Task 2: 40 minutes · 250+ words
  • Keep 3–5 minutes for checking.

Band 7–7.5 target

  • Clear Task 1 overview
  • Accurate comparisons using the visual
  • Clear Task 2 position
  • Developed main ideas
  • Controlled vocabulary and grammar

Important: The Task 1 visuals below are real reusable charts/diagrams from Wikimedia Commons and Our World in Data. Each image has a source link. These are practice tasks, not official live IELTS papers.

Task 1 structure

  1. Introduction: paraphrase the task.
  2. Overview: identify the 2–3 biggest features.
  3. Details 1: group and compare important information.
  4. Details 2: report remaining key comparisons.

Task 2 structure

  1. Introduction: paraphrase + direct answer.
  2. Body 1: idea → explanation → example.
  3. Body 2: idea → explanation → example.
  4. Conclusion: restate your position.

Final self-check

Task 1

  • Did I write a clear overview?
  • Did I compare rather than list?
  • Did I report only important features?
  • Did I use the correct tense and units?

Task 2

  • Did I answer every part?
  • Is my position clear throughout?
  • Does each paragraph have one main job?
  • Are ideas explained and supported?
  • Did I write 250+ words?
